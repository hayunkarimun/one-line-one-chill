## Entry

`main.py` (Python 3.13, stdlib only) scores seven candidate one-line horror sentences against the judge brief's four criteria — frightening, vivid, original, well-built — in the brief's own order, and writes the winner to `/output/entry.txt`.

## The line

> The dentist held up my pulled tooth and pointed inside it: my name, carved there in my own handwriting.
